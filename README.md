# Quote Villa

*Quote Villa* is a simple full-stack project where users can submit their favorite quotes and view all submitted quotes on a separate page. I built this project *after just 4 days of learning backend*, to practice connecting frontend and backend using Node.js and Express.

---

## 🔹 Features
- Submit quotes via a form on the homepage  
- View all submitted quotes on a separate page  
- Dynamic rendering using EJS templates  
- In-memory storage (quotes are lost when the server restarts)

---

## 🔹 Tech Stack
- *Backend:* Node.js, Express.js  
- *Frontend:* HTML, CSS, EJS  
- *Dev Tools:* Git, GitHub

---

## 🔹 How It Works
1. User enters a quote in the form on the homepage.  
2. Backend receives the data via POST request and stores it in an array.  
3. User is redirected to /quotes page to see all submitted quotes.  

---

## 🔹 Limitations
- No database (quotes are not saved permanently)  
- No authentication (anyone can submit quotes)  
- No likes/comments  
- Basic styling only  
- Runs locally (localhost:3000), not deployed  

---

## 🔹 Skills Demonstrated
- Backend routing (GET & POST) with Express  
- Handling form submissions and parsing data  
- Dynamic rendering with EJS  
- HTML & CSS basics  
- Arrays, loops, and data flow logic  
- Git and GitHub usage
